# カタン 挑戦者AI 対局サイト

ブラウザで遊べる「カタン」対局サイトです。従来の人間1人対AI3人に加え、オンラインで人間3人対最強AI1人の部屋を作れます。UIはすべて日本語です。

![開始画面](shots/ui-start-en.png)

---

## 使い方（コードは不要）

### いちばん簡単な方法
1. このフォルダを丸ごとダウンロードします。
2. `index.html` を **ダブルクリック** してブラウザ（Chrome / Edge / Safari など）で開きます。
3. 「対局の設定」で自分の席と相手AIを選び、「対局開始」を押すだけです。

> 一部のブラウザは `file://` で開いたときにファイル読み込みを制限することがあります。
> その場合は下の「ローカルサーバーで開く」を使ってください。

### ローカルサーバーで開く（推奨・確実）
このフォルダの中でどちらかを実行し、表示されたURL（例 `http://localhost:8000`）を開きます。

```bash
# Python がある場合
python3 -m http.server 8000

# Node.js がある場合
npx serve .
```

### インターネットに公開する（GitHub Pages・1人用）
1. このフォルダの中身を GitHub リポジトリにアップロードします（`index.html` がリポジトリ直下に来るように）。
2. リポジトリの **Settings → Pages** で、Branch を `main`（フォルダは `/root`）に設定して保存します。
3. 数分後に発行されるURLを開けば、誰でもブラウザで遊べます。

GitHub Pagesでは従来の1人用対局を遊べます。オンライン部屋はAPIが必要なため、下記のVercel版を使います。

### オンライン対戦（人間3人＋最強AI）

1. Vercel版の開始画面で「オンライン対戦」を押します。
2. 1人目が部屋を作り、表示された招待URLを残り2人へ送ります。
3. 3人が揃ったら、ホストが「3人＋最強AIで対局開始」を押します。
4. 人間はP1〜P3、最強AIはP4に入り、各端末の盤面が同期します。

部屋は最後の更新から24時間保存されます。ホストの画面がP4のAIを動かすため、対局中はホストがページを閉じないでください。

### Vercelへ配置する

このリポジトリをVercelへImportし、Vercel MarketplaceからUpstash Redisを接続します。次のどちらかの組み合わせが環境変数に設定されれば、部屋が複数のFunction間で共有されます。

```text
UPSTASH_REDIS_REST_URL
UPSTASH_REDIS_REST_TOKEN

# または
KV_REST_API_URL
KV_REST_API_TOKEN
```

ローカル確認は `npm run dev` で `http://127.0.0.1:4173` を開きます。ローカルではメモリ保存なので、サーバー再起動で部屋が消えます。

## 遊び方

- **開始画面**: 一番上で **言語（日本語 / English）** と **画面（PC / スマホ）** を選べます。続いてあなたの席（P1〜P4）と、相手AI3人のタイプを席ごとに選びます。
  - **挑戦者AI** … 高速な先読みで初期配置を選ぶ最強型
  - **現行AI** … 学習モデルによる標準型
  - 「盤面シャッフル」で公式ルールに沿った数字・港のランダム盤面を作り直せます。
  - 言語・画面モードは対局中でも上部バーのボタンでいつでも切り替えできます。
- **初期配置**: あなたの番になったら、頂点をクリックして開拓地を、続けて接する辺をクリックして道を置きます。
- **本編**: 「サイコロを振る」→ 建設（頂点=開拓地/都市、辺=道をクリック）・交易・発展カード → 「ターン終了」。
  盗賊（出目7）や捨て札、カード効果の選択も画面の指示どおりに操作できます。
- AIの3人は自動で打ちます。上部の **再生/一時停止** と **AI速度**（最速〜3.0秒）で進行を調整できます。

## 主な機能

| 機能 | 説明 |
|---|---|
| 1画面レイアウト | PCではスクロール無しで全体（盤面・手札・状況・評価値・ログ・銀行・相手）が同時に見える。伸びるパネル（ログ・評価値）はパネル内でスクロール |
| PC / スマホ 切替 | 画面幅から自動判定。手動トグルが常に優先。スマホは盤面が上・操作が下に固定、中央は状況/評価値/ログ/銀行/相手のタブ切替 |
| 日本語 / English | 開始画面と上部バーで切替。UI・ログ・棋譜まで全文言を翻訳（対局中の切替で過去ログも再描画） |
| オンライン部屋 | 招待URLまたは6桁コードで人間3人が参加し、P4の最強AIと対局 |
| 席ごとのAI選択 | 1人用では相手3席それぞれに「挑戦者AI／現行AI」を割り当て |
| 盤面シャッフル | 公式配分の数字トークン・9港のランダム盤面を生成 |
| ログ | 出目・建設・盗賊・交易・カード・勝敗を日本語で逐次表示 |
| 銀行パネル | 資源カードの残数、発展カード山札の残数、使用済み発展カードの内訳 |
| 相手パネル | 各AIのVP・手札**枚数のみ**・発展カード枚数・騎士数・最長交易路（手札の中身は非公開） |
| **AI評価値** | あなたの手番で、打てる手を `+3.2 / -1.5` のような点数付きで順位表示（目玉機能）。初期配置では候補地を盤面にハイライト |
| 棋譜確認（リプレイ） | 対局終了後、記録した各ターンの盤面・手札・出来事を◀▶で振り返り |
| 棋譜書き出し | 対局記録を `game_record.json` としてダウンロード |

![対局中とAI評価値（PC・日本語）](shots/ui-pc-ja.png)

### AI評価値について
あなたの手番中に上部の「AI評価値: ON」を押すと、AIが計算した候補手が点数順に並びます。
点数は「ターン終了（=何もしない）」を基準（±0）とした相対値で、大きい `+` ほど良い手です。
初期配置中は、盤面上に候補地の強さ（①②③のおすすめ）が色とバッジで表示されます。

## 技術メモ

- 1人用対局は従来どおりブラウザ内だけで完結します。オンライン部屋ではVercel FunctionsとRedisを使い、約0.8秒間隔で局面を同期します。
- 現行のオンライン版は気軽な対局向けです。ルール処理とAIはブラウザ側にあり、改造したクライアントへの完全な不正対策はまだ行っていません。
- ゲームエンジン（ルール処理・AI・SVG盤面描画・リプレイ）は、研究用プロジェクトの
  単一HTML（`catan_input.html`＝配置エディタ＋AI対戦モード）から**そのまま再利用**しています。
  - `js/engine.js` … 研究プロジェクトのエンジン部分。起動処理だけを新レイアウト用に最小化
    （エディタUIの初期化を外し、`resetPlacements(); randomBoard(); randomPorts();` のみ）。
    ゲームロジック・AI・`render()`・リプレイは無改変です。
  - `js/app.js` … 本サイト独自のUI・パネル・席別AIループ・評価値表示などを実装し、
    `updateGamePanel()` などを後勝ちで再定義してエンジンの版を差し替えています。
- 盤面の描画クラス（`.hexface/.token/.tokennum/.pipdot/.edge/.edgeink/.vtx/.settle`）は
  エンジンの `render()` が使うため、`css/styles.css` でも名称と役割を維持しています。

```

css/styles.css     … テーマ・レイアウト（盤面クラスを含む）
js/engine.js       … 再利用したゲームエンジン＋AI＋描画＋リプレイ
js/app.js          … 新UI・席別AIループ・評価値・リプレイ・棋譜書き出し・1画面/PC・スマホ切替・日英i18n
js/multiplayer.js  … オンラインロビー・局面同期・手番制御・再接続
api/rooms.js       … 部屋作成・参加・取得・局面更新API
api/store.js       … Upstash Redis保存（ローカル開発時はメモリ保存）
shots/             … 動作確認スクリーンショット（参考）
verify*.js         … 開発時の動作確認スクリプト（Playwright・遊ぶのに使いません）
```
