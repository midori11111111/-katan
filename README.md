# カタン 挑戦者AI 対局サイト

ブラウザで遊べる「カタン」対局サイトです。従来の人間1人対AI3人に加え、オンラインで「人間2人＋最強AI2体」または「人間3人＋最強AI1体」の部屋を作れます。UIはすべて日本語です。

![開始画面](shots/ui-start-en.png)

---

## 使い方（コードは不要）

### いちばん簡単な方法
1. このフォルダを丸ごとダウンロードします。
2. `index.html` を **ダブルクリック** してブラウザ（Chrome / Edge / Safari など）で開きます。
3. 「対局の設定」で自分の席と相手AIを選び、「対局開始」を押すだけです。

> 一部のブラウザは `file://` で開いたときにファイル読み込みを制限することがあります。
> その場合は下の「ローカルサーバーで開く」を使ってください。

### ローカルサーバーで開く（推奨・確実）
このフォルダの中でどちらかを実行し、表示されたURL（例 `http://localhost:8000`）を開きます。

```bash
# Python がある場合
python3 -m http.server 8000

# Node.js がある場合
npx serve .
```

### インターネットに公開する（GitHub Pages・1人用）
1. このフォルダの中身を GitHub リポジトリにアップロードします（`index.html` がリポジトリ直下に来るように）。
2. リポジトリの **Settings → Pages** で、Branch を `main`（フォルダは `/root`）に設定して保存します。
3. 数分後に発行されるURLを開けば、誰でもブラウザで遊べます。

GitHub Pagesでは従来の1人用対局を遊べます。オンライン部屋はAPIが必要なため、下記のVercel版を使います。

### オンライン対戦（人間2〜3人＋最強AI）

1. Vercel版の開始画面で「オンライン対戦」を押します。
2. 1人目が「人間2人＋AI2体」か「人間3人＋AI1体」を選んで部屋を作り、招待URLを残りの人へ送ります。
3. 必要人数が揃ったら、ホストが対局開始を押します。
4. 開始時に人間席の順番がランダムに入れ替わります。2人モードは人間P1〜P2・AI P3〜P4、3人モードは人間P1〜P3・AI P4です。

部屋は最後の更新から24時間保存されます。ホストの画面がすべてのAI席を動かすため、対局中はホストがページを閉じないでください。

同期確認をするときは、部屋作成前に「デバッグ部屋」をONにします。開始後、ホストだけに表示される「同期デバッグ」から、現在の手番または指定席を人力操作できます。通常の対局ではOFFのまま使います。

### Vercelへ配置する

このリポジトリをVercelへImportし、Vercel MarketplaceからUpstash Redisを接続します。次のどちらかの組み合わせが環境変数に設定されれば、部屋が複数のFunction間で共有されます。

```text
UPSTASH_REDIS_REST_URL
UPSTASH_REDIS_REST_TOKEN

# または
KV_REST_API_URL
KV_REST_API_TOKEN

# 匿名研究データを書き出す管理API専用（十分長いランダム文字列）
RESEARCH_EXPORT_TOKEN
```

ローカル確認は `npm run dev` で `http://127.0.0.1:4173` を開きます。ローカルではメモリ保存なので、サーバー再起動で部屋が消えます。

### 匿名対局データからAIを改善する

オンライン対局では、表示名・認証token・IPを研究データへ入れず、サーバーが受理した局面と各行動直前の状態を匿名IDで180日保存します。書き出しAPIは`RESEARCH_EXPORT_TOKEN`で保護され、対局クライアントへは返しません。

```bash
# Vercelから最新100対局を書き出す
RESEARCH_EXPORT_TOKEN=... npm run research:export -- \
  https://catan-challenger-online.vercel.app research_exports 100

# 研究リポジトリ側で、AIが人間に負けた局面の全合法手を同一未来乱数で比較する
node zoo.js pubgen online-site/research_exports 24 public_expert_data.jsonl 200

# 対局IDで8:2分割済み。pubaudit側は閾値決定後に一度だけ開封する
OV_AUDIT_PREFIX=pubaudit: node exfit_override.js \
  public_expert_data.jsonl public_expert_ranker.json 8 4
```

上記を一括実行し、固定SEED・データhash由来の未選択fresh seedまで機械判定する場合は、研究リポジトリ直下で次を実行します。監査または対戦に落ちたモデルは不採用として記録され、本番AIを自動更新しません。

```bash
node run_public_learning.js online-site/research_exports
```

出力先の`manifest.json`が`ready-for-human-gate`になった場合だけ、最後に学習へ使っていない強い人間との実戦へ進めます。

対局の勝敗や人間の実手をそのまま正解にはしません。負けたAI席の局面を優先して採取し、各候補を公開情報から再決定化した複数未来で比較して勝率差を教師にします。学習モデルは現行AIを全面置換せず、十分な確信がある局面だけを上書きする残差方策として評価します。

## 遊び方

- **開始画面**: 一番上で **言語（日本語 / English）** と **画面（PC / スマホ）** を選べます。続いてあなたの席（P1〜P4）と、相手AI3人のタイプを席ごとに選びます。
  - **挑戦者AI** … 高速な先読みで初期配置を選ぶ最強型
  - **現行AI** … 学習モデルによる標準型
  - 「盤面シャッフル」で公式ルールに沿った数字・港のランダム盤面を作り直せます。
  - 言語・画面モードは対局中でも上部バーのボタンでいつでも切り替えできます。
- **初期配置**: あなたの番になったら、頂点をクリックして開拓地を、続けて接する辺をクリックして道を置きます。
- **配置操作**: 「ワンタッチ」は従来どおり即時確定します。「2回タップ」は1回目で家・都市・道を仮表示し、同じ場所をもう一度押すと確定します。設定は端末に保存されます。
- **本編**: 「サイコロを振る」→ 建設（頂点=開拓地/都市、辺=道をクリック）・交易・発展カード → 「ターン終了」。
  盗賊（出目7）や捨て札、カード効果の選択も画面の指示どおりに操作できます。
- AIの3人は自動で打ちます。上部の **再生/一時停止** と **AI速度**（最速〜3.0秒）で進行を調整できます。

## 主な機能

| 機能 | 説明 |
|---|---|
| 1画面レイアウト | PCではスクロール無しで全体（盤面・手札・状況・評価値・ログ・銀行・相手）が同時に見える。伸びるパネル（ログ・評価値）はパネル内でスクロール |
| PC / スマホ 切替 | 画面幅から自動判定。手動トグルが常に優先。スマホは盤面が上・操作が下に固定、中央は状況/評価値/ログ/銀行/相手のタブ切替 |
| 日本語 / English | 開始画面と上部バーで切替。UI・ログ・棋譜まで全文言を翻訳（対局中の切替で過去ログも再描画） |
| オンライン部屋 | 招待URLまたは6桁コードで、人間2人＋AI2体または人間3人＋AI1体の対局 |
| 席シャッフル | オンライン対局開始時に人間の名前・認証・ホスト権限をまとめて人間席へランダム再配置 |
| 同期デバッグ | デバッグ部屋のホストが、現在の手番または指定した席を手動操作して不具合を再現 |
| 配置操作切替 | 家・都市・道を即時確定する「ワンタッチ」と、仮置き後に確定する「2回タップ」 |
| 席ごとのAI選択 | 1人用では相手3席それぞれに「挑戦者AI／現行AI」を割り当て |
| 盤面シャッフル | 公式配分の数字トークン・9港のランダム盤面を生成 |
| ログ | 出目・建設・盗賊・交易・カード・勝敗を日本語で逐次表示 |
| 銀行パネル | 資源カードの残数、発展カード山札の残数、使用済み発展カードの内訳 |
| 相手パネル | 各AIのVP・手札**枚数のみ**・発展カード枚数・騎士数・最長交易路（手札の中身は非公開） |
| **AI評価値** | あなたの手番で、打てる手を `+3.2 / -1.5` のような点数付きで順位表示（目玉機能）。初期配置では候補地を盤面にハイライト |
| **AI推定勝率** | 30特徴の学習評価を初期値にし、配置完了後は現在局面から本物のルールで終局までPC 512局／スマホ256局を逐次シミュレーション。乱数ダイスと未公開の残り発展カード順を毎局振り直し、有効局数と標本誤差を表示 |
| 棋譜確認（リプレイ） | 対局終了後、記録した各ターンの盤面・手札・出来事を◀▶で振り返り |
| 棋譜書き出し | 対局記録を `game_record.json` としてダウンロード |

![対局中とAI評価値（PC・日本語）](shots/ui-pc-ja.png)

### AI評価値について
あなたの手番中に上部の「AI評価値: ON」を押すと、AIが計算した候補手が点数順に並びます。
点数は「ターン終了（=何もしない）」を基準（±0）とした相対値で、大きい `+` ほど良い手です。
初期配置中は、盤面上に候補地の強さ（①②③のおすすめ）が色とバッジで表示されます。

### AI推定勝率について

上部の「勝率ゲージ: ON」を押すと、まず強者棋譜から学習した30特徴モデル（holdout AUC 0.946）を表示します。初期配置が終わった局面では、全席が現行の最強AI方策で続行すると仮定し、現在のルールエンジンそのものを複製して終局まで繰り返します。PCは512局、スマホは256局まで段階的に精密化するため、計算途中でも結果を確認して操作できます。

表示する `±` は乱数試行だけに由来する最大標本誤差です。将来の人間の打ち方による差、学習モデルの誤差、非公開情報の扱いまでは含まないため、絶対的な保証ではなく「現在のAI方策を基準にした局面勝率」として使います。

## 技術メモ

- 1人用対局は従来どおりブラウザ内だけで完結します。オンライン部屋ではVercel FunctionsとRedisを使い、約0.8秒間隔で局面を同期します。同一手番内の連続操作は最終スナップショットへまとめ、通信断は12秒で検出して状態を保持したまま自動再送します。権限違反など再送不能な応答では無限再送せず、サーバーの最新局面へ復帰します。
- 現行のオンライン版は気軽な対局向けです。ルール処理とAIはブラウザ側にあり、改造したクライアントへの完全な不正対策はまだ行っていません。
- ゲームエンジン（ルール処理・AI・SVG盤面描画・リプレイ）は、研究用プロジェクトの
  単一HTML（`catan_input.html`＝配置エディタ＋AI対戦モード）から**そのまま再利用**しています。
  - `js/engine.js` … 研究プロジェクトのエンジン部分。起動処理だけを新レイアウト用に最小化
    （エディタUIの初期化を外し、`resetPlacements(); randomBoard(); randomPorts();` のみ）。
    ゲームロジック・AI・`render()`・リプレイは無改変です。
  - `js/app.js` … 本サイト独自のUI・パネル・席別AIループ・評価値表示などを実装し、
    `updateGamePanel()` などを後勝ちで再定義してエンジンの版を差し替えています。
- 盤面の描画クラス（`.hexface/.token/.tokennum/.pipdot/.edge/.edgeink/.vtx/.settle`）は
  エンジンの `render()` が使うため、`css/styles.css` でも名称と役割を維持しています。
